# Проверки 1.12.0

Fabric Minecraft 1.20.1, Java 17.0.13, Gradle 8.7, Fabric API 0.92.2+1.20.1. Сборка и серверные проверки выполняются в новой рабочей среде; недоступная старая среда не изменялась.

**84 серверных сценария прошли без ошибок**: прежние 75 и 9 новых (8 функциональных тестов + выгрузка фактического реестра еды). [XML общего прогона](monkey-decor/tests-1.12.0.xml). Неизменённый длительный тест частоты поселений, ранее измеренный отдельно, исключён через `-PskipFrequency`; в полной регистрации 85 тестов. После финальных изменений повторно прошли 24 проверки декора и каталога еды; [XML](monkey-decor/final-decor-tests.xml).

```sh
./gradlew -PskipFrequency runGametest
./gradlew -PdecorOnly runGametest
./gradlew build
python3 tools/validate_monkey_decor.py
python3 tools/render_monkey_decor.py
```

## Сервер

- Проверены реальная установка BlockItem, четыре поворота, занятые ячейки, препятствия, удаление частей и единственность инвентаря для всех **16** видов декора, включая прежние восемь Золдракса.
- Для полки, стола, корзины и сушилки: заполнение всех слотов, расход ровно одной единицы, отказ замены занятого места/неподходящей еды, выборочное удаление и восстановление настоящего BlockEntity из NBT с идентификатором типа.
- Два игрока одновременно заполняют стол: сохраняется суммарное число продуктов; занятые места не перезаписываются.
- Корзина открывает штатный Generic3x3ContainerScreenHandler, хранит 9 полных стаков.
- На скамье два ServerPlayer занимают разные сиденья, третий отклоняется; освобождение места и разрушение части корректно высаживают пассажиров.
- Проверены задержки и повторные удары гонга/барабана.
- Пиксели настоящей карты подтверждены в клиенте, включая режим наблюдателя: доска отправляет MapUpdateS2CPacket только при первом просмотре/изменении данных. Бумага показана отдельным прикреплённым листом. Доска принимает бумагу, карту, написанную книгу; открывает LecternScreenHandler с исходными страницами, не создаёт собственного текста.
- Заполненный инвентарь не теряет возвращаемую еду: возникает ровно один ItemEntity.
- Реестр Registries.ITEM содержит 40 ванильных `isFood`; у всех есть отдельный ресурс объёмного меша. Также подготовлены торт и золотой банан.
- Прежние механики трёх божеств, почитатели, награды/рейды/доставка/обмен, происхождение алтарей и реальные структуры сохранили проходящие проверки. Новые предметы не меняют правило испытаний только у построенных игроком алтарей.

## Ресурсы

Валидатор проверяет 8 моделей мебели, 42 модели еды, корректные объёмные кубоиды, UV в границах текстуры, уникальные UUID, дерево групп, встроенные PNG, идентичность design/runtime, полный реестр еды, переводы и восемь различных рецептов. Мебель — 64×64, еда — 32×32. Программные виды исходной геометрии находятся в `monkey-decor/source/` и отдельно обозначены как source.

## Настоящий клиент

Minecraft запущен на отдельном Xvfb-экране через программный OpenGL Mesa. Development-only `MonkeyDecorClientPreview` создаёт специальный мир обзора, выставляет настоящие предметы и снимает **50 игровых кадров**: пустое/заполненное состояние, бок, задняя сторона и верх всех восьми объектов, всю ванильную еду, корзину, посадку, творческую вкладку и дополнительные комбинации еды. Исходные скриншоты не заменены художественными изображениями.

При повторном запуске клиент загрузил сохранённое содержимое полки из предыдущего мира до подготовки сцены (`MONKEY_RELOAD_VERIFIED`). Это реальный перезапуск интегрированного сервера; NBT каждого контейнера дополнительно проверен серверными тестами. Два отдельных сетевых графических клиента не запускались; одновременные транзакции и посадка испытаны с несколькими ServerPlayer в GameTest.

[Галерея игровых снимков](monkey-decor/client/README.md). Для воспроизведения подготовьте отдельное сохранение `build/monkey-client/saves/MonkeyDecorReview`, затем `./gradlew runMonkeyPreview`; команда изменяет только этот специальный мир. Не используйте для обзора своё игровое сохранение.

Звуковой движок OpenAL успешно запущен через backend `No Output`; события инструментов и анимации проходят проверку. Акустическое качество/слышимость человеком здесь не оценивались — физического аудиоустройства нет. Сохраняются прежние предупреждения shader `zoldrax:monument` о неиспользуемом Sampler2 и ошибки внешней авторизации development-профиля без Minecraft Services; критических исключений рендера нового набора не обнаружено.

## Ограничения

Модели — voxel-реконструкция перспективных концептов; скрытые поверхности восстановлены самостоятельно. Полноценный ИИ жителей, переработка пищи и автоматическая сушка не добавлялись. Корзина показывает ограниченную представительную выборку реального содержимого; неизвестная еда других модов использует резервный ItemRenderer. Чужие моды и два физических клиента отдельно не проверялись. Подробности и API: [описание 1.12.0](monkey-decor-1.12.0.md).
