# Игровые снимки декора Тернора — 1.13.0

Все PNG сняты автоматически настоящим клиентом Minecraft 1.20.1 с программным OpenGL. Используются обычный дневной или ночной свет и стандартные слои рендера; эффект ночного зрения и скрытые источники света не применялись.

Для каждого объекта сохранены пустой вид спереди, заполненный/рабочий вид спереди, вид сбоку и вид сверху. Основные заполненные состояния:

- [Садовый навес](01-ternor_garden_canopy-filled-front.png)
- [Складской стеллаж](05-ternor_storage_shelf-filled-front.png)
- [Кормушка](09-ternor_animal_feeder-filled-front.png)
- [Поилка](13-ternor_animal_trough-filled-front.png)
- [Каменный очаг-кузня](17-ternor_stone_forge-filled-front.png)
- [Кузнечные меха](21-ternor_forge_bellows-filled-front.png)
- [Закалочная бадья](25-ternor_quenching_tub-filled-front.png)

Общие сцены: [день](28-all-day.png) · [ночь](29-all-night.png).

Интерфейсы: [стеллаж](30-storage-menu.png) · [кормушка](31-feeder-menu.png) · [плавка](32-forge-smelting-menu.png) · [ремонт](33-forge-repair-menu.png).
