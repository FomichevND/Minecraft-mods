# Проверки 1.9.2

Java 17.0.13, Minecraft 1.20.1, Gradle 8.7 / Fabric Loom 1.6.12.

Прошли все 54 серверных сценария механик/структур. Неизменённый длительный сценарий частоты генерации, отдельно проверенный в 1.9.1, в этом прогоне исключён; его регистрация сохранена в полном тестовом моде (всего 55 сценариев).

Три новых регрессионных сценария:

- `discoveredTemplateAwakensForFirstVisitor`: размещается настоящий NBT `monkey/court_temple` с готовым монументом, без установки алтаря игроком. Пока игрок далеко, заказа нет; после приближения сам начинается испытание с полным сроком, UUID первого гостя и сохранённым флагом знакомства.
- `legacyUnvisitedShrineStartsOnUseAndCannotReset`: старый найденный алтарь без нового флага и с далёким NextRequest просыпается по настоящему обработчику ПКМ. Повторный ПКМ не меняет еду и дедлайн; состояние сохраняется при чтении/записи NBT.
- `oldCompletedChallengeKeepsCooldown`: данные старого алтаря с историей испытания сохраняют задержку после загрузки и взаимодействия; недостроенный алтарь не запускает заказ.

Прежние проверки наград, рейдов, строительства, NPC, доставки, урожая, моделей поселений и биомов также прошли. Геометрия и текстуры не менялись. Игровой клиент не запускался.
