# Декор Золдракса 1.11.0

Fabric 1.20.1, Java 17, прежний Fabric API; новые зависимости мода не добавлены. Восемь предметов находятся во вкладке **«Культ Золдракса»**. У каждого собственная геометрия, PNG 256×256, рецепты из ванильных материалов и RU/EN-переводы.

| Объект / ID после `zoldrax:` | Использование | Основание / зарезервированная высота |
| --- | --- | --- |
| `zoldrax_throne` | ПКМ — сесть; повторный ПКМ или Shift — встать. Один игрок одновременно. | 2×1 / 3 блока; геометрия ~2,5 блока |
| `zoldrax_brazier` | ПКМ пустой рукой — огонь вкл./выкл.; свет 15, дым, красные искры, тихое потрескивание. | 1×1 / 2 |
| `zoldrax_skull_lamp` | ПКМ пустой рукой — свет 12 вкл./выкл.; светящиеся глазницы и стержень. | 1×1 / 2 |
| `zoldrax_chain_lantern` | Установка снизу потолка. ПКМ пустой рукой — свет 14 вкл./выкл.; Shift+ПКМ пустой рукой — подвес 1/2 блока при наличии места. | 1×1 / 3 или 4 вниз от крепления |
| `zoldrax_weapon_rack` | ПКМ с оружием — поместить один предмет; пустой рукой — забрать последний. Три видимых слота. | 2×1 / 3; геометрия ~2,2 |
| `zoldrax_chest` | ПКМ — стандартные 27 слотов. Подвижная крышка, собственное сочетание звуков, воронки сверху/снизу/сбоку, компаратор. | 1×1 / 2 |
| `zoldrax_lectern` | ПКМ с книгой — поставить; ПКМ — читать; Shift+ПКМ — забрать, в том числе с занятой рукой. | 1×1 / 2 |
| `zoldrax_offering_pedestal` | ПКМ — поставить один предмет; Shift+ПКМ — забрать. Предмет парит/вращается; камни дают красные частицы. | 1×1 / 2 |

Направление фасада выбирается при установке. Технические части занимают нужные ячейки, имеют формы выбора/коллизии из исходной геометрии и не создают отдельного инвентаря. Разрушение любой части удаляет объект и возвращает один предмет блока вместе с содержимым. Подвес требует потолка, остальные объекты — основания (сундук допускает воронку под собой). Поршни объекты не перемещают. Декоративный огонь не наносит урон и не распространяется.

Теги для расширения через datapack: `zoldrax:rack_weapons`, `zoldrax:lectern_books`, `zoldrax:pedestal_gems`. Поддерживаются необязательные `c:scrolls` и `c:gems`. Книги Minecraft открываются штатным интерфейсом; собственные свитки отображаются как предметы, а их специальные экраны требуют интеграции соответствующего мода.

## Файлы

- Код: `DecorKind`, `DecorBlocks`, `DecorBaseBlock`, `DecorBlock`, `DecorBlockEntity`, `DecorSeatEntity`, `DecorRenderer`, сгенерированный `DecorGeometry`.
- Редактируемые модели: `design/blockbench/` и идентичные runtime-копии `assets/zoldrax/models/blockbench/decor/`. Имена моделей совпадают с ID предметов.
- 777 отдельных кубоидов, включая открытые звенья цепей, зубы/глазницы, сегменты рогов, крепления и выступающие руны. У сундука отдельная крышка, у фонаря — подвес/клетка, у пюпитра — книга.
- Текстуры: `assets/zoldrax/textures/block/zoldrax/`; blockstate/item-модели делегируют полноценному renderer, читающему `.bbmodel`.
- Генераторы: `tools/generate_zoldrax_decor.py`, `tools/generate_decor_data.py`; проверка `tools/validate_decor.py`; программные виды `tools/render_decor_preview.py`.
- Рецепты/loot/теги: `data/zoldrax/`; скрытые части не выпадают отдельно. Имена/подсказки: `lang/ru_ru.json`, `lang/en_us.json`.

## Сравнение с референсами

| Модель | Перенесённые детали |
| --- | --- |
| Трон | Высокая багровая спинка и большое полотнище, крупные верхние/боковые рога, два черепа на подлокотниках, цепи, мягкое сиденье и дорожка на ступени. |
| Жаровня | Открытая ступенчатая восьмиугольная чаша, четыре рога, передний череп/знамёна, объёмные языки огня и нижняя руна. |
| Черепной светильник | Большой объёмный череп с зубами/носовой полостью, симметричные рога, красный стержень и каменное основание с руной. |
| Цепной фонарь | Открытые чередующиеся звенья, металлическая клетка с красным ядром, боковые рога и нижний костяной шип. |
| Оружейная стойка | Две колонны/рога, перекладина/верхний череп, красные полотнища, цепи, три крюка и видимое настоящее оружие. |
| Сундук | Красная подвижная крышка с трещинами, рога, передний череп, цепи на фасаде и боках, боковые полотнища, красные прорези. |
| Пюпитр | Наклонная столешница/книга, рога, колонна, цепи, переднее полотнище и руна. |
| Подставка | Чаша с двумя рогами, череп, полотнища, красный стержень/руны и объёмный кристалл, заменяемый выставленным предметом. |

Пропорции адаптированы к сетке Minecraft и функциональным проходам; обратные/скрытые поверхности реконструированы. Перспективная иллюстрация не задаёт точных ортографических размеров. Программные виды спереди/сбоку/сзади/сверху находятся в `docs/decor/*-source.png`; они отдельно обозначены и не выдаются за игровые скриншоты.

В обычном Minecraft свет блоков не бывает цветным: красными сделаны сами emissive-элементы, ядра и частицы, а освещение окружения использует стандартный свет движка. Сиденье — невидимая синхронизируемая сущность транспорта, без видимой стойки для брони. Содержимое и переключатели сохраняются; соединение разных серверов/дополнительных модов отдельно не испытывалось.

Существующие механики трёх божеств сохранены. Испытания Короля Обезьян по-прежнему доступны **только у алтарей, установленных и построенных игроком**.
