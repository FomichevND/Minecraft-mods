# Проверка версии 1.9.0

- Java 17.0.13, Gradle 8.7, Fabric Loom 1.6.12, Minecraft 1.20.1.
- Чистая сборка `gradle clean build` успешна; итоговый распространяемый архив — `build/libs/zoldrax-monument-1.9.0.jar` после remapJar.
- `gradle runGametest`: **50 из 50 обязательных серверных сценариев прошли**.
- `python3 tools/validate_models.py`: UV, встроенные и внешние PNG, кости, размеры монументов, плоские лица и белки глаз проверены.
- В серверных сценариях проверены прежние механики всех трёх божеств, NPC, подношения, настоящая логистика продуктов, пересадка урожая, обмен и сохранение торговой задержки.

- Оба святилища размещены из NBT с поворотом: готовый монумент, пять постоянных жителей, правильные роли, отсутствие столкновений и опоры фонарей/знамён/лестниц проверены.

- Фактические координаты, высоты и повороты из этого прогона: `banana_court-1.9.0-generation.json`, `great_appetite_valley-1.9.0-generation.json`; схема — `monkey-settlements-1.9.0-layout.png`.
