# Функциональный декор Тернора — 1.13.0

Набор рассчитан на Minecraft 1.20.1, Fabric Loader 0.15.11+, Fabric API 0.92.2+1.20.1 и Java 17. Все семь предметов находятся во вкладке **«Поселение Тернора»**, имеют отдельные рецепты, многоблочное размещение и редактируемые исходники Blockbench.

| Объект | Размер | Использование |
| --- | --- | --- |
| Садовый навес | 3×3×3 | ПКМ подходящим цветком, саженцем, грибом, лианой или ягодами ставит одну объёмную модель в ящик. Shift+ПКМ пустой рукой возвращает последнее растение. |
| Складской стеллаж | 3×1×3 | ПКМ открывает 27 слотов. До девяти реальных представителей содержимого видны на полках. |
| Кормушка | 2×1×1 | ПКМ открывает 9 слотов только для корма. Реальное заполнение показано плотной объёмной насыпью по всей внутренней площади. |
| Поилка | 2×1×2 | Ведро воды заполняет четыре уровня. Коровы, овцы и свиньи подходят и периодически выпивают один уровень. |
| Каменный очаг-кузня | 3×2×3 | ПКМ открывает ванильный ремонт с обычным расходом материала и опыта; Shift+ПКМ открывает плавку. Огонь, свет, дым и искры появляются только при работе. |
| Кузнечные меха | 2×1×2 | ПКМ запускает видимое сжатие и даёт ближайшей кузне ускорение на 10 секунд. Повторный запуск обновляет таймер и не складывает усиление. |
| Закалочная бадья | 1×1×1 | Ведро воды даёт четыре уровня. Повторная плавка слитка в кузне делает его горячим на 30 секунд; ПКМ горячей заготовкой запускает рецепт закалки, пар и шипение. |

Кормушка не переводит животных в режим любви и не создаёт бесконтрольного размножения. Между срабатываниями одной станции проходит 30 секунд, одно животное обслуживается не чаще раза в пять минут. Вода и корм расходуются реально.

Кузня использует ванильные правила наковальни и печные рецепты. Она не лечит и не ремонтирует стража Тернора. Закалка расширяется datapack-рецептами типа `zoldrax:quenching`; стандартные рецепты железа, золота и меди возвращают тот же слиток с меткой `TernorTempered`, не добавляя обязательных руд и не меняя боевой баланс.

Для будущих поселений подготовлены три поворачиваемых NBT-шаблона:

```mcfunction
/place template zoldrax:ternor/workshop
/place template zoldrax:ternor/farmyard
/place template zoldrax:ternor/storehouse
```

Они не включены в самостоятельную естественную генерацию, потому что в текущем проекте ещё нет системы поселений Тернора. Публичный `TernorWorkstationApi` уже позволяет будущим NPC запускать меха, пополнять воду и переносить допустимые предметы, не обходя фильтры инвентарей.

Невидимые стороны реконструированы по общей каменно-деревянной стилистике референсов. Навес не ускоряет рост растений, чтобы не пересекаться с эффектами основного монумента. AI кузнеца, фермера и кладовщика оставлен для следующего этапа; сами рабочие станции и API готовы. Все текстуры используют спокойные ванильные материалы и обычное освещение Minecraft; полное свечение оставлено только пламени.
