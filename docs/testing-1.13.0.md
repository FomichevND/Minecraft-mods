# Проверки 1.13.0

Сборка выполняется на Java 17 для Minecraft 1.20.1, Fabric Loader 0.15.11 и Fabric API 0.92.2+1.20.1.

- `python3 tools/validate_ternor_decor.py` — пройдена проверка семи редактируемых моделей, 41 объёмной модели растений/ресурсов, трёх NBT-шаблонов и трёх рецептов закалки.
- `runGametest -PternorOnly` — 11 из 11 сценариев Тернора прошли.
- `runGametest -PdecorOnly` — 36 из 36 сценариев всего функционального декора прошли.
- `runGametest -PskipFrequency` — 96 из 96 обязательных регрессионных сценариев прошли. Исключён только медленный статистический поиск частоты поселений Короля Обезьян; его алгоритм и данные не менялись.
- `runTernorPreview` — клиент Minecraft с программным OpenGL завершился успешно и создал 34 снимка: четыре ракурса каждого объекта, дневная/ночная сцены и четыре интерфейса.

GameTest проверяет размещение и удаление всех частей во всех направлениях, препятствия и коллизии, один дроп конструкции, сохранение предметов и состояний, реальные контейнеры, фильтры воронок, ремонт с расходом материала и опыта, плавку, горячие заготовки и datapack-рецепты закалки. Для животных проверены расход одной порции, отсутствие режима размножения и сохранение задержек. Три шаблона поселений размещены во всех четырёх поворотах; каждая часть правильно находит корневой `block entity`.

Полный набор также повторно проверяет прежние монументы, NPC, культы, отдельные здания и правило происхождения алтаря Короля Обезьян. Испытания остались доступны только у алтаря, построенного игроком.
