# Редактируемые модели Короля Обезьян

Открывайте .bbmodel в Blockbench как Generic Model. PNG встроены; отдельные файлы находятся в ZIP/textures и runtime-ресурсах. Мебель — 64×64, еда — 32×32. 16 единиц координат = 1 блок, +Z — фасад, +Y — вверх.

Runtime читает идентичные .bbmodel напрямую. После редактирования перенесите файл из design в assets/zoldrax/models/blockbench/decor или food и обновите ресурсы F3+T. Поля zoldrax_group/zoldrax_emissive задают группы; стандартный outliner также поддерживается. Группы gong/drum — подвижные части инструментов. При изменении внешних размеров мебели обновите MonkeyDecorGeometry и занятые ячейки DecorKind; генератор воспроизводит геометрию из своего исходного описания и перезаписывает ручные правки.

Скрытые поверхности восстановлены самостоятельно по перспективным референсам. Объёмные модели еды используют собственные пиксельные текстуры с узнаваемыми ванильными цветами.
