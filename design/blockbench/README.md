# Декор Золдракса — Blockbench

Восемь `.bbmodel` открываются в Blockbench как Generic Model. Текстура 256×256 встроена в каждый файл; отдельные PNG лежат в ресурсах мода. Размеры — в пикселях Minecraft (16 = блок), передняя сторона +Z, вертикаль +Y. Все черепа, рога, звенья цепей и крепления состоят из редактируемых кубоидов.

Runtime читает **те же** модели из `assets/zoldrax/models/blockbench/decor/`. После ручного редактирования перенесите файл туда; при изменении геометрии обновите серверные формы `DecorGeometry.java` (генератор `tools/generate_zoldrax_decor.py` создаёт формы из своего исходного описания и перезаписывает модели). Клавиша F3+T перезагружает ресурсы/кеш мешей клиента.

Группы `lid`, `flame`, `cage`, `chain`, `extension`, `book`, `crystal` используются рендерером для анимаций/видимости. Нестандартные поля `zoldrax_group` и `zoldrax_emissive` явно задают группы/свечение. Если Blockbench удаляет их при сохранении, renderer восстанавливает группы из стандартного outliner, а свечение — по UV-ячеечкам rune/fire/crystal атласа; сохраняйте эти имена групп и расположение материалов. Поворот крышки сундука: [8,14,3]. Дополнительное звено подвеса и клетка фонаря переводятся вниз при удлинении.

Реконструкция выполнена по двум приложенным иллюстрациям. Силуэты и характерные детали перенесены в Minecraft voxel-геометрию; скрытые поверхности и обратные стороны восстановлены самостоятельно. Это не заявление о точном совпадении всех пикселей с перспективным концептом.
