# Объёмная еда Minecraft 1.20.1

40 съедобных ID получены из настоящего Registries.ITEM. Дополнительно есть торт и золотой банан. Каждый .bbmodel — редактируемая кубическая модель, со встроенной собственной PNG 32×32. Полный список IDs: docs/monkey-decor/vanilla-food-catalog.json. Привязки runtime: assets/zoldrax/food_models.json.

После правки скопируйте .bbmodel в assets/zoldrax/models/blockbench/food и отдельную PNG в textures/block/zoldrax. Отображение нормируется по габаритам; исходная ориентация +Y вверх, +Z вперёд. Продукт стоит нижней гранью на столешнице; для сушилки renderer выбирает подвес за верхнюю часть.
